GTA 6 Spoiler Shield

An element is hidden when it mentions a topic term and a spoiler term, or any always-block phrase. Matching ignores case, accents, punctuation and extra spaces, and only matches whole words. One term per line.

Behavior

Display mode

What counts as "about GTA 6". Spaces inside a term are optional ("GTA 6" also matches "GTA6", "gta-6").

Characters, places and words like "ending". Terms of 4+ letters also match plurals ("mission" → "missions"). Add new names here.

Hidden on their own, even without a topic term. Use specific phrases, e.g. a full character name plus "dies".

Removed before looking for topic terms, so "GTA 5" or "GTA Online" never satisfy the topic requirement.

Paste a headline to see whether the current (unsaved) lists would hide it.

Where it runs

By default the shield only has access to YouTube, Reddit, Instagram and Facebook. To cover news sites and every other page (the generic fallback), allow access to all websites. Chrome will then warn that the extension can "read and change all your data on all websites". Nothing leaves your browser either way; see the README for the tradeoff.
